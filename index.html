使い方

    

      
基本の流れ

      
    
        
  1. 商品リストにカテゴリ・型番・税別価格・コメントを入れる（スプレッドシートからの貼り付けも可）
    2. 
        
  2. フォントと、なぞりガイドの薄さを決める
    3. 
        
  3. レイアウトを選ぶ（台紙に合わせたものが無ければ、下の「台紙に合わせる」を参照）
    4. 
        
  4. 「印刷 / PDF」を押す
    5. 
      

      
台紙（他店対抗の赤いヘッダーなど）に合わせる

      
    
        
  1. 台紙を画像（PNG / JPEG）にする。POP作成ソフトから PDF に出力して画像に変換するか、印刷したものをスキャン
    2. 
        
  2. 「他店対抗 A4縦」を「複製して自分用に」→「レイアウトを編集」→「画像を選ぶ」で台紙を登録
    3. 
        
  3. プレビュー上で各項目の枠をドラッグして、台紙の書く場所に合わせる（右下をつまむと大きさ変更）
    4. 
        
  4. 白紙に印刷すると台紙となぞりガイドが一度に出ます。台紙が印刷済みの用紙を使うなら、台紙を登録せず位置だけ合わせてその用紙に印刷
    5. 
        
  5. できたレイアウトは「パックを保存」→ 他の端末で「パックを取り込む」で共有（台紙画像ごと運べます）
    6. 
      

      
PC（Chrome / Edge）で印刷するとき

      
    
        
  • 印刷画面の「余白」は 既定 または なし にする（余白はレイアウト側で持っています）
    • 
        
  • 用紙サイズはレイアウトに合わせて自動で選ばれます。カスタム寸法の場合はプリンタ側で合わせてください
    • 
        
  • 薄すぎる／濃すぎるときは「薄さ」スライダーか、プリンタの濃度設定で調整
    • 
      

      
iPhone / iPad（Safari）でPDFにするとき

      
    
        
  1. 「印刷 / PDF」→ プリント画面が開く
    2. 
        
  2. プレビューの用紙をピンチで拡大するとPDFとして開く
    3. 
        
  3. 共有ボタン →「"ファイル"に保存」または店のPCへ送る
    4. 
        
  4. 用紙サイズはプリント画面の「用紙サイズ」で合わせてください（自動で変わらないことがあります）
    5. 
      

      
Android（Chrome）でPDFにするとき

      
  1. 「印刷 / PDF」→ プリンタの選択で「PDF形式で保存」

      
レイアウトを他の端末でも使う

      
    
        
  • 台紙なし: 「共有（URL / QR）」で出たURLを他の端末で開くと取り込めます
    • 
        
  • 台紙あり: 「パックを保存」したファイルを相手の端末で「パックを取り込む」
    • 
        
  • 全端末の標準にしたいレイアウトは「JSONをコピー」して管理者に渡してください（台紙画像は含まれません）
    • 
      

      
データの保存について

      
入力内容・設定・自作レイアウト・台紙画像はこの端末のブラウザ内にだけ保存されます。どこにも送信されません。
