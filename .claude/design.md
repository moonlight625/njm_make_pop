# design.md（設計判断と理由）

## 2026-10-10 初期設計

### 静的サイト + ブラウザ印刷にした
- 入力 → DOM描画 → `window.print()` で完結し、サーバーもPDFライブラリも不要
- PDF生成ライブラリ（jsPDF等）は日本語フォント埋め込みが重く、ブラウザの印刷→PDF保存で同じ結果が得られる
- iPad/スマホも同じ仕組み（iOSは共有→"ファイル"に保存、Androidは「PDF形式で保存」）

### 用紙の表現
- `.sheet` を mm 指定の固定サイズ div にし、CSS grid で `cols × rows` のセルを配置。余白は padding、間隔は gap
- 画面では `.sheet-wrap`（スケール後の px サイズ）の中で `.sheet` を `transform: scale()` 縮小。印刷時は print.css で transform を外し実寸
- `@page { size: WmmHmm; margin: 0 }` を `#page-style` に JS で書く。Chrome は自動でこの用紙を選ぶ（iOS Safari は無視することがある）
- 文字サイズは「セル高さ × 項目の高さ比 × 項目ごとの基準比（型番0.5 / 金額0.62 / コメント0.3）× 倍率」で mm → px 計算し、
  `fitText()` で枠からはみ出す分だけ 8% ずつ縮める（型番・金額は幅、コメントは高さで判定）

### なぞりガイドの2方式
- 塗り: `color: hsl(0 0% L%)`（L=薄さスライダー）
- 輪郭: `color: transparent; -webkit-text-stroke`（Chrome/Edge/Safari で動作。Firefox は非対応だが対象外）

### レイアウトのデータ
- 組込み（`data/layouts.json`、全端末共通）+ 自作（localStorage、端末ごと）の2層
- 組込みは編集不可にし「複製して自分用に」で自作を作る方式。組込みを直接いじれると push で上書きされて混乱するため
- 共有は `#layout=base64url(JSON)` のURL（≈500バイト、QRに収まる）。取り込み時は必ず id を振り直し組込みと衝突させない
- 「全端末の標準にする」は JSON を layouts.json に手で追記して push。サーバーを持たないための割り切り
- 将来 API 化するときは `fetchBuiltin()` の差し替えだけで済むようにしてある

### フォント
- Google Fonts の OFL 日本語手書き系 6書体（7ファイル）を `pyftsubset --flavor=woff2` で日本語範囲だけ残して自前配置（合計約15MB）
- `@font-face` は全部宣言するが、ブラウザは使った書体しか取得しない。「全フォントを見比べる」を開いたときだけ全部読む
- Google Fonts CDN を使わない理由: 店のネットワークで外部フォント配信がフィルタされる可能性を避ける
- 一覧は `fonts.json` マニフェスト。追加は「ファイルを置く + 1行足す」で済むように
- 再配布できないフォント向けに「この端末にフォントを追加」（File API → FontFace → IndexedDB）

### 金額の扱い
- 入力は自由テキスト。数字だけなら blur でカンマ付与、描画時に `¥` / `円` / なし を設定で切替
- 「税込」など文字が混ざっていればそのまま出す（店の表記の自由度を残す）

## 2026-10-10 v2: 台紙＋自由配置に変更

### きっかけ
- 現物の上貼りは「店のPOP作成ソフト（Mighty POP）で赤ヘッダー・税別・（税込 円）を印刷した台紙」に、
  商品名＋型番 / 税別価格（赤ペン・大） / 税込価格 / ひとことコメント を手書きしていた
- 「白紙に3項目を縦積み」のモデルでは台紙に合わないので、**項目ごとに x/y/w/h（セルに対する %）で置く**モデルに変更

### データモデル
- fields: name / model / price / priceTax / comment。各 `{enabled, x, y, w, h, align, sizeScale, color}`
- `color` はガイド色（gray / red / blue）。赤ペンで書く価格は薄いピンクのガイドにするため
- priceTax は入力しない。税別 × (1 + 税率%) を切り捨てて自動表示（税率は設定、既定10）
- 旧 v1（heightPct 縦積み）は `normalize()` が v2 に変換し、読み込み時に localStorage へ書き戻す
- グリッド（cols × rows）は維持。セル単位のテンプレートを敷き詰める形なので、台紙付き1件でも白紙4件でも同じコード

### 台紙画像
- 会社ロゴ・マスコット入りなので **リポジトリに置かない**。端末の IndexedDB（`pop-backgrounds`）に保存し、レイアウトは id で参照
- 共有URL / layouts.json 用 JSON からは背景 id を外す（端末固有のため）
- 端末間は「パック」（layout JSON + 画像 base64 を1ファイル）で運ぶ。`.pop-layout.json`
- `<img>` で描画（CSS background にしない）。`<img>` は印刷ダイアログの「背景のグラフィック」設定に関係なく印刷される
- レイアウト削除時、他で使っていなければ画像も消す

### 位置合わせ UI
- 自作レイアウトで「レイアウトを編集」を開いている間だけ `#preview.editing`。枠に点線・項目名・右下ハンドルを出す
- pointer events でドラッグ移動、右下 18px 内をつかむとリサイズ。0.5% 刻み。離した時点で normalize → 保存 → 再描画
- 印刷ボタン押下時は editing クラスを外す（print.css でも二重に隠す）

### 商品リストを table → grid にした理由（実バグ）
- 5列の table では左パネル幅でコメント欄の内容幅が 0 以下になり、**Chrome で IME 入力（insertText）が常に先頭へ挿入され文字列が逆順になる**
  （puppeteer で再現・最小ページで「内容幅 ≤ 0 のとき発生」を確認）
- 2行構成の grid（1行目: 商品名/型番/税別/枚数/操作、2行目: コメント全幅）にして各欄に十分な幅を確保

### サンプル台紙（2026-10-10 追記）
- 管理人の「台紙も作ってもらえる？」に応えて、写真の構成（赤ヘッダー「他店徹底対抗!」「どこよりもお買い得に挑戦!」、税別、（税込 円））を
  **ロゴ・マスコットなし**で再現した `tools/taisei-sample.svg` を作成。会社の識別要素は含めないので公開リポジトリに置ける
- フォント依存を無くすため、Mac の Hiragino で A4 300dpi PNG（`data/bg/taisei-sample.png`、約150KB）に焼いて配布
- レイアウトの `background.url`（リポジトリ内パス）を追加。`id`（端末 IndexedDB）と排他で、ユーザーが画像を選ぶと url は消える
  - url は共有URL / layouts.json にそのまま載る（公開物なので）。パックでも url 参照のまま
  - 安全のため normalize で `..` を含まない相対パス・画像拡張子のみ許可
- 組込み `a4p-taisei` の項目位置は SVG の設計値（mm）から % に換算して確定。本物の台紙に差し替えたらドラッグで再調整する前提

### Canva 製台紙を組込みに採用（2026-10-10）
- 管理人が Canva（大学アカウントの有料プラン）で作った A4 台紙（2828×4000px）を `data/bg/taisei.png` として組込み `a4p-taisei` に設定
- 文字と基本図形のみでストック素材を含まないため、Canva のライセンス（Education アカウントの Pro 素材は非商用限定 / Pro 素材の再配布禁止）に
  抵触しないと判断して公開リポジトリに置いた。**ストック素材（写真・イラスト・Resource）を含む台紙は今後も repo に入れず、パック配布にする**
- 項目位置は Pillow で画像を解析して決めた: 白ボディ y=1683..3882、下線 y=2000（x 223..2604）、税別 y≈2090..2220、（税込 x 1140..1494 / ) x 2550..2600、y 3649..3799
- 旧 SVG サンプルは `a4p-taisei-sample`（簡易サンプル台紙）として残した

### 2026-10-10 UI調整（管理人要望）
- 「商品名」→「カテゴリ」に表示変更。内部キーは `name` のまま（保存済み localStorage / layouts.json を壊さないため）
- Enter で行追加する挙動を廃止（IME 確定の Enter と衝突して誤追加しやすい）。代わりに各行に「＋」（この下に挿入）を追加
- 商品リスト直下に「項目の位置・大きさを調整する」ボタンと案内文。組込み選択中に押すと確認のうえ複製して編集を開く
- 枠のドラッグは用紙の端で止めない（パワポ同様に外へ出せる）。normalize も x/y -200..200、w/h 1..300 に緩和
  編集中は `.sheet` `.pop` の overflow を visible にして外にはみ出た枠を見せる。印刷時は overflow hidden に戻るので用紙外は切れる
